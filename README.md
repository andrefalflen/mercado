# Sistema de Gestão de Estoque

## Nome do projeto

Sistema de Gestão de Estoque para Mercado

## Objetivo

O objetivo deste projeto é desenvolver um sistema simples para controlar os produtos de um mercado.

O sistema permite cadastrar, visualizar, editar e excluir produtos do estoque.

O projeto foi desenvolvido utilizando PHP e MySQL, com Prepared Statements para realizar as operações no banco de dados.

---

## Tecnologias utilizadas

- PHP
- MySQL
- HTML
- CSS
- Git
- GitHub
- XAMPP
- MySQL Workbench

---

## Requisitos

Para executar o projeto é necessário ter instalado:

- XAMPP
- PHP
- MySQL
- Navegador de internet
- MySQL Workbench (opcional)
- Git (para versionamento)
